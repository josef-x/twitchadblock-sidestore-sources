# TwitchAdBlock SideStore Source

A SideStore source that automatically provides the latest builds of **TwitchAdBlock** from [gunnerkidBT/TwitchAdBlock](https://github.com/gunnerkidBT/TwitchAdBlock).

This source makes it easy to install and receive updates for the modified Twitch app with ad blocking and extra features, without having to manually download IPAs from GitHub Releases.

## Source URL

Add this URL in SideStore:
https://twitchadblock.josef-x.xyz/

## What’s included

This source provides **two versions** of the app:

| App Name                        | Description                                      | Recommended for          |
|--------------------------------|--------------------------------------------------|--------------------------|
| **TwitchAdBlock**              | Full version with plugins / app extensions       | Paid Apple Developer account |
| **TwitchAdBlock (No Plugins)** | Lightweight version (uses only 1 App ID)         | Free Apple ID            |

### Features
- Blocks live stream and VOD pre-roll ads (via proxy)
- Removes feed ads, sponsor spots, and the “Go Ad-Free” button
- 7TV, BetterTTV, and FrankerFaceZ emotes in chat
- Keep Live Feed Playing
- Settings backup & restore
- Diagnostics screen
- Launch screen picker
- Hide Twitch Stories

## How to add the source

1. Open **SideStore**
2. Go to the **Sources** tab
3. Tap the **+** button
4. Paste: `https://twitchadblock.josef-x.xyz/`
5. Tap **Add**

The source will automatically stay up to date with new releases.
